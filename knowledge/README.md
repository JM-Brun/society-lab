# Knowledge base

La base de connaissance contient la taxonomie, les tags, les types de relations et les fiches de concepts, institutions et mécanismes. Les définitions doivent être contextualisées, sourcées et reliées aux objets de recherche.

- `TAXONOMY.yml` : domaines.
- `domains/` : pages thématiques de synthèse et de navigation ; la page [Éducation](domains/education.md) est le premier exemple.
- `TAGS.yml` : vocabulaire transversal contrôlé.
- `RELATION_TYPES.yml` : ontologie légère des relations.
- `GRAPH.md` : principes du graphe.
