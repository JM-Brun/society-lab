# Licences et réutilisation

## État actuel du dépôt

Le dépôt a été initialisé avec un fichier `LICENSE` contenant la GNU General Public License v3 (GPL-3.0). Cette licence est adaptée à certains logiciels, mais elle n'est pas nécessairement le meilleur choix pour tous les contenus d'un projet mêlant documentation, données, code et ressources tierces.

Ne pas supposer que cette licence autorise la redistribution de documents ou de jeux de données externes : leurs propres conditions restent applicables.

## Politique cible à examiner

Avant d'ajouter une licence globale ou de remplacer la licence actuelle, décider explicitement d'une politique par catégorie :

- textes originaux et documentation : envisager CC BY 4.0 ;
- code original : envisager MIT ;
- données originales : licence explicite adaptée à leur nature ;
- données et documents tiers : licence du fournisseur, conditions d'accès et attribution ;
- extraits : respect du droit de citation et des limites applicables.

## Décision requise

La licence actuelle ne doit pas être remplacée automatiquement. Une décision explicite est nécessaire sur la compatibilité entre la GPL-3.0 déjà présente et une éventuelle politique multi-licences. En attendant, chaque contribution doit respecter la licence existante et les droits des tiers.
