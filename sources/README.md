# Sources

- `registry.yml` : index léger des sources.
- `records/` : fiches individuelles si le volume le justifie.
- `batches/` : manifestes d'ingestion en lot.

Une entrée de registre n'est pas une validation de la source. Voir [protocole d'ingestion](../docs/ingestion-protocol.md) et [politique des sources](../docs/source-policy.md).
